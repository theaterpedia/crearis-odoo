# Theaterpedia Odoo Module

Crearis Odoo Module is a custom module for Odoo that integrates with the Crearis platform, providing enhanced functionality for managing theaterpedia-related data.
## Features
- Integration with Crearis API for data synchronization of orgs and freelancers.
- Management of theaterpedia-root entries and their associated data.
- Templates for creating and managing theaterpedia entries.

## Templates
The module includes templates for event and partner theaterpedia entities, which can be used to quickly import local data into the Odoo system.
